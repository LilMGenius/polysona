## What happens next

Polysona is being rewritten **completely from scratch**. Not a refactor, not a
migration — a new codebase starting from this empty commit.

The hackathon build proved the idea under a 0-touch constraint: it had to work, and
it had to be built by the harness alone. That constraint shaped every decision in it.
The rewrite drops those constraints and keeps only the thesis: **persona as a
first-class primitive**, portable across any AI agent.

**Branch layout**

| Branch | Purpose |
|---|---|
| [`ralphthon`](https://github.com/LilMGenius/polysona/tree/ralphthon) | Frozen hackathon source. Default branch. Read-only in spirit. |
| `dev` | The from-scratch rewrite. Starts here, at commit #1. |

`main` is retired for now. It will come back when the rewrite has something worth
shipping.
